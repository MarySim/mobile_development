# Лабораторная работа №0: Базовые алгоритмические конструкции на Kotlin

**Дисциплина:** Разработка мобильных приложений Уменьшить
**Выполнила:** студентка группы ФИТ-241, Симонова Марина Евгеньевна

## Описание проекта
Данный проект представляет собой набор консольных программ, разработанных в рамках выполнения нулевой лабораторной работы. 
Проект включает в себя реализацию 10 независимых алгоритмических задач, объединенных в единую точку входа.

## Технологический стек
* **Язык программирования:** Kotlin
* **JDK:** 21 (Oracle OpenJDK)
* **Среда разработки:** IntelliJ IDEA
* **Система сборки:** Встроенная (IntelliJ) / Gradle

## Структура проекта
Исходный код располагается в директории `src/main/kotlin`. Основной файл программы — `Main.kt`.
Внутри файла реализована функция `main()`, выступающая в роли диспетчера запуска, и 10 отдельных функций (`task1()` — `task10()`), каждая из которых инкапсулирует логику конкретного задания.

## Инструкция по запуску и проверке
Для удобства, запуск каждого задания изолирован. 

1. Откройте файл `Main.kt`.
2. В функции `main()` представлен список всех задач. 
3. Чтобы запустить конкретную задачу, **раскомментируйте** соответствующую строку.
