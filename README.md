## Цель работы

## Структура репозитория
Работа состоит из трех независимых проектов, созданных на базе шаблона **Empty Views Activity**. Все проекты изолированы в собственных директориях для предотвращения конфликтов Gradle-сборок.

### 1. FirstApp
Базовое ознакомительное приложение («Hello World»).  
**Освоенные навыки:**
- Создание проекта в Android Studio.
- Запуск приложения на виртуальном эмуляторе (AVD).
- Базовая структура Android-проекта.

### 2. LinearLayout
Приложение для изучения статической верстки и работы с ресурсами.  
**Реализованный функционал:**
- Перевод корневого макета в `LinearLayout` с вертикальной ориентацией (`orientation="vertical"`).
- Обработка системных отступов (Edge-to-Edge) через `ViewCompat.setOnApplyWindowInsetsListener` с привязкой к `android:id="@+id/main"`.
- Размещение трех компонентов `TextView`:
  1. Вывод ФИО и номера группы (хардкод).
  2. Вывод стихотворения на русском языке (хардкод).
  3. Вывод перевода стихотворения на английский язык с использованием файла строковых ресурсов (`res/values/strings.xml`).

### 3. Components
Интерактивное приложение с обработкой пользовательского ввода.  
**Реализованный функционал:**
- Использование поля ввода `EditText` для получения имени пользователя.
- Использование `CheckBox` для подтверждения статуса («Я студент ФИТ-241»).
- Размещение статического изображения через `ImageView`.
- Обработка события нажатия на кнопку (`Button.setOnClickListener`) на стороне Kotlin-кода.
- Валидация данных: проверка поля ввода на пустоту.
- Динамическое формирование строки результата и ее вывод в `TextView` (например: «Привет, Marina! Твой статус: студент ФИТ-241» или статус гостя).

## Запуск проектов
1. Открыть выбранную папку проекта (например, `Lab1/Components`) в Android Studio.
2. Дождаться завершения синхронизации Gradle.
3. Выбрать доступный эмулятор (AVD) или подключенное физическое устройство.
4. Нажать `Run 'app'` (Shift + F10).
