# Лабораторная работа №3: Начало работы с Jetpack Compose

**Дисциплина:** Разработка мобильных приложений  
**Студент:** Симонова Марина Евгеньевна (ФИТ-241)  

## Цель работы
Ознакомиться с базовыми конструкциями современного декларативного UI-фреймворка Jetpack Compose, изучить основные элементы (Text, Image) и контейнеры (Column, Row, Box).

## Реализованные проекты (Lab3)
1. **HappyBirthday:** Открытка с фоновым изображением и наложенным текстом с использованием контейнера `Box` и `ContentScale.Crop`. Строки локализованы через `strings.xml`.
2. **ComposeArticle:** Верстка экрана статьи с картинкой и текстами, выстроенными вертикально (`Column`) и выровненными по ширине (`TextAlign.Justify`).
3. **TaskManager:** Минималистичный экран завершения задач с центрированием элементов по осям и точечными отступами (`padding`).
4. **ComposeQuadrant:** Сетка из четырех равных цветных квадратов. Реализована через вложенные `Column` и `Row` с использованием `Modifier.weight(1f)`.
5. **MyInformation:** Личная цифровая визитка разработчика с кастомными цветами, импортированной фотографией (`drawable-nodpi`) и векторными иконками Material Design Extended.
