## Структура проектов (Lab2)

### 1. ToastHandler
Приложение для работы с базовыми событиями и всплывающими уведомлениями.  
**Реализованный функционал:**
- Поиск UI-элементов через `findViewById`.
- Установка обработчика событий `OnClickListener` на кнопку.
- Вызов всплывающего уведомления с помощью класса `Toast` (`Toast.LENGTH_SHORT`).

### 2. Logging
Приложение для изучения инструментов отладки и системного логирования.  
**Реализованный функционал:**
- Работа со стандартным классом `android.util.Log` (уровень Verbose, тег "From EditText").
- Интеграция сторонней библиотеки `Timber` через файл сборки `build.gradle.kts` (Version Catalogs).
- Инициализация дерева `Timber.plant(Timber.DebugTree())` и отправка скрытых логов без ручного указания тегов.
- Мониторинг вывода данных через системную консоль **Logcat**.

### 3. Attributes
Приложение для динамического изменения внешнего вида компонентов интерфейса.  
**Реализованный функционал:**
- Динамическое изменение цвета текста (`setTextColor`) с использованием констант класса `Color`.
- Программное изменение размера шрифта (`textSize` в формате `Float`).
- Динамическое изменение цвета фона поля ввода (`setBackgroundColor`).
- Сложная верстка: использование вложенных `LinearLayout` (горизонтальных внутри вертикального) для табличного расположения кнопок с применением `layout_weight`.
