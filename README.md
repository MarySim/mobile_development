# Лабораторная работа №5. Взаимодействие с UI и состоянием. Тесты

**Дисциплина** — «Разработка мобильных приложений»

**Выполнила** — Симонова Марина Евгеньевна, ФИТ-241, КемГУ

## Цель работы

Изучить обработку действий пользователя, сохранение состояния в Jetpack Compose и автоматизированное тестирование Android-приложений.

## Проекты

- **TipTime** — калькулятор чаевых. Сумма счёта и процент вводятся отдельно, результат обновляется при вводе, а переключатель округляет чаевые вверх. Введённые значения сохраняются при повороте экрана. Стартовые ресурсы и тема взяты из [учебного проекта Google](https://github.com/google-developer-training/basic-android-kotlin-compose-training-tip-calculator/tree/starter).
- **ArtSpaceApp** — галерея из трёх произведений с подписями и циклическим переключением. Выбранная работа сохраняется при повороте экрана. В альбомном режиме изображение и кнопки с подписью расположены рядом.

## Запуск и проверка

Откройте папку нужного проекта в Android Studio, дождитесь синхронизации Gradle и запустите конфигурацию `app` на эмуляторе или устройстве. Оба проекта используют Kotlin DSL и поддерживают Android API 24 и выше.

В `TipTime` модульный тест `TipCalculatorTests` и Compose UI-тест `TipUITests` проверяют расчёт чаевых для счёта 10 и процента 20. Ожидаемая сумма — 2 в валюте устройства. Для запуска UI-теста нужен эмулятор или подключённое устройство.
